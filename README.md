# UCB - Projetos do 1º módulo

Este repositório reúne projetos desenvolvidos durante o 1º módulo da faculdade, com foco em HTML e CSS.

## Descrição

Os exercícios foram realizados para praticar e reforçar conceitos de:

- estruturação de páginas com HTML
- estilização com CSS
- layout e organização visual
- uso de imagens, textos e seções
- criação de interfaces simples e funcionais

## Estrutura do projeto

- `index.html` — página principal do projeto
- `assets/css/style-index.css` — estilos da página inicial
- `assets/css/ironforce.css` — estilos específicos da página Iron Force
- `assets/pages/ironforce.html` — segunda página do projeto
- `assets/img/` — imagens e elementos visuais utilizados no layout

## Objetivo

Aplicar na prática os conhecimentos adquiridos em Front-End, criando páginas com visual limpo, organizado e funcional.

## Tecnologias utilizadas

- HTML5
- CSS3

## Observação

Este projeto foi desenvolvido como atividade acadêmica para testar e demonstrar o conhecimento adquirido no 1º módulo da UCB.
