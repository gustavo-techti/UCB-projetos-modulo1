# UCB - Projetos do 1º módulo

Este repositório contém projetos desenvolvidos no 1º módulo da faculdade, com foco em HTML e CSS.

## Sobre o projeto

Os exercícios foram criados para praticar e consolidar conhecimentos de:

- estruturação de páginas com HTML
- estilização e layout com CSS
- organização visual de elementos
- uso de imagens, textos e seções
- criação de interfaces simples, atrativas e funcionais

## Estrutura do projeto

- `index.html` — página principal do projeto
- `assets/css/style-index.css` — estilos da página inicial
- `assets/css/ironforce.css` — estilos específicos da página Iron Force
- `assets/pages/ironforce.html` — segunda página com visual complementar
- `assets/img/` — imagens e elementos visuais utilizados no layout

## Objetivo

Aplicar na prática os conceitos aprendidos em Front-End, criando páginas com visual limpo, organizado e profissional, além de reforçar a lógica de estrutura e estilo.

## Tecnologias utilizadas

- HTML5
- CSS3

## Observação

Este projeto foi desenvolvido como atividade acadêmica para testar e demonstrar o conhecimento adquirido no 1º módulo da UCB.

## Como visualizar localmente

1. Abra o arquivo `index.html` em um navegador.
2. Para acessar a página secundária, utilize o arquivo `assets/pages/ironforce.html`.
3. Caso queira, também é possível abrir o projeto em um editor como o VS Code e visualizar em Live Server.
