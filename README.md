# UCB - Projetos do 1º módulo

Este repositório reúne atividades desenvolvidas no 1º módulo da faculdade, com foco em HTML e CSS.

## 🚀 Sobre o projeto

Os exercícios foram criados para praticar e reforçar conhecimentos em:

- estruturação de páginas com HTML
- estilização e layout com CSS
- organização visual de elementos
- uso de imagens, textos e seções
- criação de interfaces simples, modernas e funcionais

## 📁 Estrutura do projeto

- `index.html` — página principal do projeto
- `assets/css/style-index.css` — estilos da página inicial
- `assets/css/ironforce.css` — estilos específicos da página Iron Force
- `assets/pages/ironforce.html` — página secundária com visual complementar
- `assets/img/` — imagens e elementos visuais utilizados no layout

## 🎯 Objetivo

Aplicar na prática os conceitos de Front-End, criando páginas com visual limpo, organizado e profissional, além de reforçar a lógica de estrutura e estilização.

## 🛠️ Tecnologias utilizadas

- HTML5
- CSS3

## 📌 Observação

Este projeto foi desenvolvido como atividade acadêmica para testar e demonstrar o conhecimento adquirido no 1º módulo da UCB.

## ▶️ Como visualizar localmente

1. Abra o arquivo `index.html` em um navegador.
2. Para acessar a segunda página, utilize `assets/pages/ironforce.html`.
3. Se preferir, abra o projeto no VS Code e use a extensão Live Server para visualizar em tempo real.

## ✅ Conclusão

O projeto representa uma aplicação prática dos conteúdos estudados em HTML e CSS, com foco em design, organização visual e apresentação de páginas web.
